# PFDB_API

How to install: (until I make pre-compiled binaries)
1. Download .NET 8 SDK and ASP.NET 8 SDK
2. Download Python 3.14 (earliest version)
3. Download Tesseract (For Linux, install the package using your package manager of choice. For Windows, download a binary and set an environment variable to tell PyTesseract where to look)
4. Download source code
5. Set up Python virtual environment
6. Download opencv-python and pytesseract with pip in the virtual environment
